# Frontend intro components and shape loader

Checked: 2026-11-06 · Status: answered; phone verification required
Feeds: frontend intro polish, entry transition, shared loading indicators. Research only; no dependencies installed or app code changed by this note.

## Questions

1. Which actual free Watermelon and Skiper components fit a phone-first entry?
2. What do their source and licenses require, and what accessibility work remains?
3. Is the requested native `MorphLoader` available as a suitable web component?

### Concrete candidates: source matters more than the catalog label

**Watermelon Shimmer Button — useful native-button structure; omit shimmer for Pata.** The [component page](https://ui.watermelon.sh/animated-components/shimmer-button) advertises Motion, but the [actual public registry item](https://registry.watermelon.sh/r/shimmer-button.json) has `dependencies: []`; its code imports `cn` from local utils and uses ordinary `<button>` props, a decorative child and CSS transform on hover. It contains no Motion import and no reduced-motion branch. The registry's empty dependency list does not supply the missing local `cn` helper. Inference: its native semantics and contained decoration are useful references, while hover shimmer adds little on phones and conflicts with the approved quiet finish. Reimplement a short pressed response and visible focus instead of copying the sweep. Read 2026-11-06; verified by docs and complete registry source.

**Watermelon Morphing Button — reject as the entry control.** [Docs](https://ui.watermelon.sh/animated-components/morphing-button) describe expansion; [registry source](https://registry.watermelon.sh/r/morphing-button.json) reveals an email signup widget with focus transfer, an outside `mousedown` listener, `motion` and `react-icons` dependencies, layout springs, and a fixed expanded `w-84` class. No `useReducedMotion`, media-query guard, or Escape close handler appears in the inspected file. Its button is click activated, so the core activation is not hover-only. Inference: the state-driven transformation is a useful concept, but its signup state, mouse-specific outside handling and width require unnecessary adaptation for one-tap entry. Do not add these packages merely for the intro. Read 2026-11-06; verified by docs and complete registry source.

**Skiper CssLink / `skiper40` — strongest restrained CTA reference.** [Docs](https://skiper-ui.com/v1/skiper40) mark it Free; [registry source](https://skiper-ui.com/r/skiper40.json) implements underlines with pseudo-elements and arrows with inline SVG. Actual imports are React, Next Link and local `cn`; registry metadata lists `framer-motion` despite no import, and docs list `lucide-react` despite inline SVG. Arrow transitions have `motion-reduce:transition-none`, but underline transitions lack an equivalent guard. Hover effects have no corresponding `focus-visible` treatment. `Link001` opens a new tab. Inference: borrow the restrained underline/arrow idea for optional decoration, but make the entry a native button, always understandable without hover; keep its label/arrow visible on touch, add keyboard focus, and suppress every transition under reduced motion. Retain Skiper attribution if adapting its source. Read 2026-11-06; verified by docs and complete registry source.

**Skiper Text roll navigation / `skiper58` — typography reference to avoid for this wordmark.** [Docs](https://skiper-ui.com/v1/skiper58) mark it Free; [registry source](https://skiper-ui.com/r/skiper58.json) uses `framer-motion`, per-character duplicated layers, `whileHover`, and `lineHeight: 0.75`. No reduced-motion or focus equivalent appears, and the repeated text layers have no `aria-hidden` separation. Inference: this needs accessibility and touch adaptations and can clip serif shapes; render approved cream “Pata” as one normal text node in the existing system serif stack. There is no need for a typography runtime or third-party font request. Read 2026-11-06; verified by docs and complete registry source.

**Skiper Apple play button / `skiper3` — relevant click-to-expand pattern, not a turnkey doorway.** [Docs](https://skiper-ui.com/v1/skiper3) and [source](https://skiper-ui.com/r/skiper3.json) show a free click-toggle, fixed width interpolation from 60 to 330, and `framer-motion` springs. Source includes blur effects and no reduced-motion check. Inference: trigger a state transition explicitly on click as it does, but avoid its player scaffolding, fixed widths, blur and new dependency. Read 2026-11-06; verified by docs and complete registry source.

### Requested MorphLoader

- The exact native component/package named `MorphLoader` could not be established from the provided name and shape list. Public search results include unrelated components with that name; do not claim a package match.
- The first seven requested shapes **do** exactly match the first-party AndroidX Material 3 indeterminate loading sequence: SoftBurst, Cookie9Sided, Pentagon, Pill, Sunny, Cookie4Sided, Oval. [AndroidX `LoadingIndicator.kt`](https://raw.githubusercontent.com/androidx/androidx/androidx-main/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/LoadingIndicator.kt) defines that list, accepts custom polygon sequences, cycles back to the first shape, and combines morphing with rotation. Its header is Apache-2.0. It preserves square aspect ratio and normalizes/caches shape morphs. This is Kotlin/Compose source, not a React component. Pin and flower are Pata's custom additions; the official default does not include a heart. Read 2026-11-06; verified by primary source code.
- Watermelon's [public morph catalog query](https://ui.watermelon.sh/api/v1/catalog/entries?kind=animated-components&query=morph&limit=50) returned eight control/layout examples, including Morphing Button and Morphing Discovery Bar, but no matching shape loader. This is a bounded query, not proof that no loader exists anywhere in its catalog. The reviewed Skiper patterns likewise are UI transitions rather than this nine-shape loader. Read 2026-11-06; verified by public API and sources above.
- A separate first-party web project, [shape-morph](https://shape-morph.thereallo.dev/docs), describes a TypeScript port of Android `androidx.graphics.shapes` with SVG/CSS/canvas output; its [Tailwind guide](https://shape-morph.thereallo.dev/docs/guides/tailwind) lists the relevant named shape utilities. This establishes a possible future route, not a vetted dependency: package source, exact version and license were not fully audited here. Do not install or copy it on this note alone. Read 2026-11-06; verified by project docs.

## Decision

Implementation recommendations below are **Pata-specific inference**, not claims of features supplied by either library.

- Keep the approved deep forest-green intro and normal cream serif Pata text. No logo in the intro; the rounded forest-green/gold app icon belongs in the ordinary header. Use locally owned text/CSS rather than importing a decorative typography component.
- Use a clearly labeled native `button type="button"` for tap-to-enter. One state transition opens the doorway into the existing home. Fit decoration to the available phone width, use a generous minimum tap height (48px recommendation), and keep controls visible at short viewport heights and enlarged text sizes.
- Animate only decorative panels using opacity/transform; keep transition time short and bounded. Do not require View Transition API, wheel/scroll gestures, pointer tracking, hover, external images, or a new animation runtime. Keyboard Enter/Space must activate it; move focus to a meaningful home heading after entry and keep hidden home controls out of the tab sequence while covered.
- Under `prefers-reduced-motion: reduce`, finish entry immediately or with an opacity-only change and suppress movement. Do not make home availability depend solely on `animationend`/`transitionend`; these can fail to fire when motion is disabled or interrupted.
- Gate only the home route. Preserve direct `/c`, `/approve`, `/setup`, `/lookup` and other route access; do not inspect, clear, or rewrite sensitive courier fragments for the intro. Browser storage failure must never trap entry. Browser APIs belong in a client effect under this static-export app.
- For loaders, create one local SVG/CSS component whose ordered shapes are **soft-burst → cookie-9-sided → pentagon → pill → sunny → cookie-4-sided → oval → supplied location pin → flower → repeat**. Use the supplied PNG alpha as a mask if its exact silhouette must be retained. A mask crossfade is a visual approximation, not geometric path interpolation; describe it honestly. True SVG morphs require compatible contour sampling/commands, particularly for a pin's hole. Keep `currentColor` support, white on green buttons, a fixed footprint and a smaller inline variant; treat 120px as the standalone reference size rather than making ordinary buttons 120px tall.
- Tie loader visibility to actual existing async state. Preserve readable pending labels and a single accessible status announcement; hide decorative geometry from assistive technology. Reduced motion should show a stable shape and loading text. Stop frame loops/timers on unmount or completion, and do not add loader announcements on every morph.
- Use namespaced global selectors such as `.pata-intro-*` / `.pata-loader-*`. Local [next.config.ts](../../next.config.ts) applies a Tailwind loader to `*.css`; the implementation session observed that it strips CSS Module export maps. That runtime observation is supplied by the implementing agent; this research did not reproduce it. Avoid CSS Module imports until that configuration issue is independently resolved.

## Test at kick-off

- [ ] Phone portrait/landscape, narrow 320px width, short screen and enlarged text: no clipped wordmark, doorway or CTA.
- [ ] Keyboard-only entry and post-entry focus; no hidden home actions in the intro tab order.
- [ ] Reduced motion before load and changed while running: no trapped overlay, no looping loader motion.
- [ ] Direct courier fragment and all other deep links bypass the home intro intact.
- [ ] Repeated taps, interrupted animations and unavailable storage still reach home once.
- [ ] Green-button loading labels remain legible; pin appears in the specified sequence; success/error exits stop the loop.
- [ ] Static export succeeds without new runtime packages or external font/image requests.
