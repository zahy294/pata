# P1-2: who-can-find-my-door and history screens

- **Goal:** the household sees every live grant with a countdown and can stop it, and the list empties by itself when a grant expires. History shows every grant it issued and how each one ended.
- **Read first:** ADRs 0002, 0005, 0008; the P0-12 plan (revoke); `arkiv.md` Gotcha 3 (no expiry events).

## Seams tested

- `listLiveGrants` and `listHistory` (Arkiv module), with a mocked RPC.
- `loadLiveAccess`, `stopAccess`, `finishInterruptedStops` and `timeLeft` (`src/lib/flows/access.ts`).
- `consentRecords` and `loadConsentHistory` (`src/lib/flows/history.ts`).
- `listUnfinishedRevocations`, against real IndexedDB in Chrome (`store.browser.spec.ts`).

## Edge cases handled

| Case                                                                      | Handling                                                                                                                                                                 |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Approval refreshed a deadline, leaving two payloads under one label       | The list shows the label once, with the later deadline, and reads its ENS status once; history keeps the later "issued" entry                                            |
| A list or history read fails                                              | A plain sentence. The last list stays on screen, and a failure is never shown as an empty list                                                                           |
| A check is still running when the next poll is due                        | One check at a time (`setTimeout` after each finishes), as the courier page learned                                                                                      |
| The page is in the background                                             | Polling pauses while `document.hidden`                                                                                                                                   |
| A poll that started before a stop landed returns the stopped grant        | Labels stopped on this page stay hidden                                                                                                                                  |
| A stop is cut off after the ENS name is released                          | The grant can no longer appear in the live list, so `finishInterruptedStops` resumes it from the device checkpoint on the next visit (payload delete, "revoked" history) |
| Stop tapped on a grant that just expired                                  | "already-ended": no transaction, and the screen says it had ended on its own                                                                                             |
| A history row from another owner, or one that won't open, or is malformed | Skipped                                                                                                                                                                  |
| A stop whose "issued" entry is missing                                    | Still shown, as "Stopped by you"                                                                                                                                         |
| Countdown reaches zero before the next poll                               | The row dims to "Ending now" and its Stop button is disabled                                                                                                             |

## Result

Live chains, localhost, a phone-sized browser on 2026-11-07:

- A 15-minute grant was listed with "14 min" left. "Stop access now" took about 40 s, then showed "Dbg Chai 9vy can no longer find your door", and the list stayed empty through later polls. The courier link then showed "This link has ended" with only "Bandra Kurla Complex, 400051".
- A 20 s grant appeared in the list and left it by itself about 15 s later, without a tap.
- History showed two records: "Ended on its own" and "Stopped by you", each with when it was shared and when it ended.
