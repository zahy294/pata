**Result:** speech-input code and mocked checks are implemented in small checked commits after the plan commit. `transcribe` sends original WebM/Opus or MP4/AAC bytes to `saaras:v4` in `codemix`, with mapped language and server-only auth. It bounds transcripts to the extraction contract and discards provider errors. The adapter accepts an empty declared MIME type to sniff bytes for the existing route context and an optional pre-upload callback for validated-duration charging, avoiding repeated server container parsing.

- The portable, work-bounded inspector validates size, container layout and coded duration, including streaming WebM without a duration header and fragmented MP4. It rejects concatenated containers and cannot be bypassed by shortened headers or overlapping timestamps. Supported profile: one non-laced Opus track or one AAC track; unsupported/indeterminate inputs fail closed. It does not decode audio, and conservative padding may reject clips close to 30 seconds; stop the recorder around 28 seconds. Actual phone compatibility/Worker CPU remain unverified.
