# P0-13: Stranger lookup

**Goal:** a household name shows only its locality (tickets.md P0-13). The door, DIGIPIN and room number stay sealed.

**Code:** `src/lib/ens/lookup.ts` `lookupLocality` reads the two public text records (`location`, `eth.pata.pincode`) through the Universal Resolver over Anon-RPC. `src/lib/flows/lookup.ts` `lookupHousehold` is the screen's entry: it accepts a bare label or the full name and returns `null` for a malformed or unregistered name without a chain read.

**Post-merge review fix (2026-11-06):** setup writes `location` as `"Dharavi, 400017"` (`ens/household.ts` `localityCalls`), so the lookup returned the pin code twice. `lookupLocality` now strips the appended `, <pin>`; the test uses the real record format.

**Tests:** `src/lib/ens/lookup.test.ts`, `src/lib/flows/lookup.test.ts`. The screen (`src/app/lookup/page.tsx`) is frontend work.
