# P0-2: parent names

**Goal:** `pata.eth` and `digipin.eth` registered on Sepolia's ENSv2; `pata.eth`'s own registry deployed and emancipated; its subregistry pointer locked once the first household works (ADR 0003).

**Files:** `scripts/register-parent-names.mjs`, `scripts/lock-pata.mjs`. The owner runs both; no agent reads `.env.local`.

**On-chain values read 2026-11-06** (public reads, Sepolia):

| Value                                       | Read                                                                 |
| ------------------------------------------- | -------------------------------------------------------------------- |
| `MIN_COMMITMENT_AGE` / `MAX_COMMITMENT_AGE` | 60 s / 86,400 s                                                      |
| `MIN_REGISTER_DURATION`                     | 2,419,200 s (28 days)                                                |
| MockUSDC is a payment token                 | true; 6 decimals                                                     |
| `pata` for 5 years                          | 550.000031 MockUSDC                                                  |
| `digipin` for 2 years                       | 14.000037 MockUSDC                                                   |
| Signatures                                  | checked against `contracts/deployments/sepolia/*.json` at `07e55a05` |

**Steps (register-parent-names.mjs, idempotent, `--dry-run` simulates only):**

1. Deploy `pata.eth`'s UserRegistry proxy through the VerifiableFactory, salt `keccak256(abi.encode(keccak256("UserRegistry"), namehash("pata.eth"), 0))`. `initialize` gives the relay and the deployer only registrar + renew roles and their admins: no role in `UNEMANCIPATED_ROLE_BITMAP`, so `isEmancipated()` is true.
2. Mint MockUSDC to the deployer and approve the ETHRegistrar.
3. Commit, wait 60 s, register `pata` (5 years, subregistry = the proxy) and `digipin` (2 years, no subregistry, no resolver until P1-1). Owner = deployer.
4. Print the proxy address, `isEmancipated()`, `verifyContract()`, and both statuses.

**Later (lock-pata.mjs, irreversible):** revoke `ROLE_SET_SUBREGISTRY | ROLE_SET_SUBREGISTRY_ADMIN` on `pata` in the ETHRegistry from the deployer, only after a household has registered through `/register`.

**Risks:** if a name is taken between check and register, use the fallbacks in `shared/constants.ts`. If `initialize` rejects the role set, fall back to the docs' example and re-check `isEmancipated()` before announcing the address.
